2. タグ部分だけを変える仕組み

一般的な comment.todo は既存テーマが前景色用に定義していることがある。そこでextension固有のcapture名を使い、タグ範囲にだけ明るい color と background_color を設定する。タグ以外は通常の comment captureのまま。

旧方式

;; TODO: p.? を正規化する

テーマ既定の文字色だけが適用される場合がある。

v0.3.3

タグ文字は明るいFrappé Text、タグ以外は通常コメント色のまま。

captureは comment.todo_tag_highlighter.task、.info、.fix、.warning。設定がない場合は一般的な comment へfallbackする。

4. 使用中テーマ用の設定を作る

Zedの settings.json に、現在のテーマ名をkeyとした theme_overrides を追加する。このgeneratorは初期値としてタグ文字 #c6d0f5、Frappé palette、dark-mode向け12% alphaを使う。

重要: 現在のtheme keyは "Catppuccin Frappé - No Italics"。Zedのtheme selector表示と完全一致させる。
preset
theme JSONから読込 browser内だけで処理し、外部へ送信しない。通常コメントstyleを読み込み、タグ文字色は別に指定できる。
手動入力

python3 scripts/generate_active_theme_overrides.py --appearance dark \

# 使用中テーマ本来のstatus色を使う場合
python3 scripts/generate_active_theme_overrides.py \
  --appearance dark \

# highlighted tagの文字色を明示
python3 scripts/generate_active_theme_overrides.py \
  --appearance dark \
  --tag-color '#c6d0f5ff'

    
scriptはsettingsとinstalled themeを読むだけで、設定ファイル自体は変更しない。見つからない場合は --theme-file または --comment-color を指定する。タグ文字は --tag-color で個別指定できる。

  


  

    
5. まだ背景が出ない場合

    

      
capture
dev: open highlights tree view でTODOに comment.todo_tag_highlighter.task が付くか確認。comment.todo しか出ないなら旧版が動いている。

      
theme名
theme_overrides のkeyはselectorのtheme名と完全一致。アクセント記号、空白、Dark/Light suffixも含む。

      
Semantic Tokens
semantic_tokens: "full" はTree-sitterを置換する。まず off で確認し、必要なら combined を使う。

      
明るさ
タグ文字は #c6d0f5。8桁HEXの末尾が背景alpha。#eebebe00 は透明、#eebebe1f は約12%、#eebebeff は不透明。Frappéでは 1f を標準にしている。

7. Galleryへ公開する方法

    
自分だけで使うなら不要。 Dev Extensionのままで利用できる。

    

      
manifestを実値へ変更
authors と repository を公開値へ変更し、versionを管理する。

      
public GitHub repositoryへpush
rootにlicenseを置く。本packageにはMIT Licenseを同梱。

      
zed-industries/extensionsをfork
extensionを extensions/todo-tag-highlighter にpublic HTTPS submoduleとして追加する。

      
registry manifestを更新
registry側の extensions.toml にID・path・versionを追加し、指定のsort commandを実行する。

      
Pull Request
「タグ部分だけ明るい文字色と背景」「タグ以外は通常コメントstyle」「Clojureを含む主要言語」の差分を説明する。
